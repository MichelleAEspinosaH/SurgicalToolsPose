# Archive

Older scripts, experiments, and sample assets from earlier development.
**Not required** to run the current pipeline — see the root [README](../README.md) for `live_pose_any.py`.

## Layout

| Folder | Contents |
|--------|----------|
| `legacy_live/` | Previous live tracking scripts (`live_track.py`, `live_track_copy.py`, `live_track_pose.py`) |
| `experiments/` | One-off tests, YOLO trainers, SAM2/SAM3 prototypes, debug utilities |
| `samples/sam3d_bootstrap/` | Example GLB meshes from early SAM3D bootstrap runs |
| `weights/` | `yolo26n-seg.pt` and other legacy model weights |

## Note

These files are kept for reference. Imports and paths may assume the old repo layout (`tests/`, `EdgeTAMLive/live_track.py`, etc.). Update paths if you reuse a script.
